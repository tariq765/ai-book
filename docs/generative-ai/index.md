# Part II: Modern Generative AI

**Chapters 5–8**

---

## Overview

Generative AI has transformed what's possible with AI. This part covers the foundations of generative models, LLMs, transformers, and prompt engineering.

## Chapters

| Chapter | Title | Key Concepts |
|---------|-------|--------------|
| 5 | [Generative AI](/generative-ai/chapter-5-generative-ai) | Text, image, audio, video generation; multimodal models |
| 6 | [Large Language Models](/generative-ai/chapter-6-large-language-models) | Tokens, parameters, context, pre-training, fine-tuning |
| 7 | [Transformers](/generative-ai/chapter-7-transformers) | Attention, self-attention, encoder-decoder architecture |
| 8 | [Prompt Engineering](/generative-ai/chapter-8-prompt-engineering) | System prompts, few-shot, structured output, templates |

## Learning Objectives

By the end of this part, you will:

- Understand how generative models create content
- Grasp LLM architecture, training, and inference
- Understand the transformer architecture that powers modern AI
- Master prompt engineering techniques

## Prerequisites

- Part I: Foundations (recommended)
- Basic Python programming
- Understanding of neural networks (Chapter 4)
