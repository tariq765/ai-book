## How to Use This Book

### Progressive Learning
Each chapter builds on previous concepts. We recommend reading sequentially, but you can jump to specific topics if you have prior knowledge.

### Visual Learning
Complex concepts are explained with:
- Architecture diagrams
- Flowcharts
- Code examples
- Real-world analogies

### Practical Focus
Theory is paired with practical examples. You'll see not just *what* concepts are, but *how* to apply them.

### Code Examples
Code snippets are in Python unless otherwise noted. They're designed to be:
- Readable and educational
- Runnable (or clearly marked illustrative)
- Modern and idiomatic

## Learning Paths

### 🎯 Complete Beginner
**Time**: 3-6 months  
Read all chapters sequentially. Complete exercises and experiments.

### 🚀 Software Developer → AI Engineer
**Time**: 1-3 months  
Focus on Parts II-VI. Skip or skim Part I fundamentals.

### 🤖 LLM Application Builder
**Time**: 2-4 weeks  
Focus on Parts II, III, IV, V. Reference other parts as needed.

### 🦾 Robotics/Physical AI Engineer
**Time**: 2-3 months  
Strong focus on Parts I, IV, VIII. Prerequisite: Parts II-III.
