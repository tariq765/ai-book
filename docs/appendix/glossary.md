# Glossary

---

## A

**Agent** — An autonomous AI system that can perceive its environment, reason about it, and take actions to achieve goals.

**Agentic AI** — AI systems that exhibit agency: they can plan, reason, use tools, and execute multi-step workflows autonomously.

**AGI (Artificial General Intelligence)** — Hypothetical AI with human-level cognitive abilities across all domains.

**Alignment** — Ensuring AI systems act in accordance with human values and intentions.

**API (Application Programming Interface)** — A set of rules allowing software components to communicate.

**Attention Mechanism** — A neural network component that weighs the importance of different input elements.

## B

**Backpropagation** — Algorithm for training neural networks by computing gradients and updating weights backward through the network.

**Batch Size** — Number of training examples processed in one forward/backward pass.

**Benchmark** — Standardized test for evaluating model performance.

**Bias (Neural Network)** — Learnable parameter added to weighted inputs before activation function.

## C

**Capability** — A specific ability or skill that an AI system possesses.

**Chat Completion** — LLM API mode that maintains conversation context across turns.

**Chunking** — Splitting documents into smaller pieces for embedding and retrieval.

**Context Window** — Maximum number of tokens an LLM can process at once.

**Convergence** — Point where training loss stops improving significantly.

## D

**Deep Learning** — Machine learning using multi-layer neural networks.

**Diffusion Model** — Generative model that learns to denoise data (used for image generation).

**Distillation** — Training a smaller model to mimic a larger model's behavior.

**Document Ingestion** — Process of loading, chunking, and indexing documents for RAG.

## E

**Embedding** — Dense vector representation capturing semantic meaning of text, images, or other data.

**Epoch** — One complete pass through the entire training dataset.

**Evaluation** — Systematic assessment of AI system performance using metrics and test data.

**Explainability** — Ability to understand and interpret AI decisions.

## F

**Fine-tuning** — Further training a pre-trained model on domain-specific data.

**Few-shot Prompting** — Providing examples in the prompt to guide model behavior.

**Function Calling** — LLM capability to output structured function calls for tool execution.

## G

**Generative AI** — AI that creates new content (text, images, audio, video).

**Gradient Descent** — Optimization algorithm that minimizes loss by moving in the direction of steepest descent.

**Grounding** — Connecting AI outputs to verifiable sources or reality.

## H

**Hallucination** — AI generating plausible but factually incorrect information.

**Hidden Layer** — Neural network layers between input and output.

**Human-in-the-Loop** — System design where humans review or guide AI decisions.

## I

**Inference** — Running a trained model to make predictions or generate output.

**Instruction Tuning** — Fine-tuning on instruction-response pairs to improve instruction following.

## L

**LLM (Large Language Model)** — Transformer-based model trained on massive text corpora.

**Local AI** — Running AI models on local hardware rather than cloud APIs.

**Loss Function** — Mathematical function measuring model prediction error.

## M

**MCP (Model Context Protocol)** — Open standard for connecting AI models to external tools and data sources.

**ML (Machine Learning)** — Algorithms that learn patterns from data without explicit programming.

**Model** — Trained mathematical representation that maps inputs to outputs.

**Multi-Agent System** — Multiple AI agents collaborating to solve complex tasks.

## N

**Neural Network** — Computing system inspired by biological neurons, composed of interconnected nodes.

**Neuron** — Basic unit of a neural network: weighted sum + bias + activation.

**NLP (Natural Language Processing)** — AI field focused on understanding and generating human language.

## O

**Observability** — Ability to understand system internal state from external outputs (logs, metrics, traces).

**Overfitting** — Model memorizing training data instead of learning generalizable patterns.

## P

**Parameter** — Learnable weight in a neural network (also called weights).

**Prompt Engineering** — Crafting effective inputs to guide LLM behavior.

**Pre-training** — Initial training on large corpora to learn general language understanding.

## Q

**Quantization** — Reducing model precision (e.g., 32-bit → 4-bit) for smaller size and faster inference.

**Query** — User input or search term used for retrieval.

## R

**RAG (Retrieval-Augmented Generation)** — Technique combining retrieval from knowledge base with LLM generation.

**Reinforcement Learning** — Learning through trial and error with rewards/penalties.

**Reranking** — Re-ordering retrieved results by relevance using a more sophisticated model.

## S

**Self-Attention** — Attention mechanism relating different positions of a single sequence.

**Supervised Learning** — Learning from labeled input-output pairs.

**System Prompt** — Instructions defining AI behavior, separate from user prompts.

## T

**Temperature** — Sampling parameter controlling randomness in LLM output.

**Token** — Basic unit of text processing in LLMs (word, subword, or character).

**Transformer** — Neural network architecture using self-attention, powering modern LLMs.

**Training** — Process of optimizing model parameters on data.

## V

**Vector Database** — Database optimized for storing and querying high-dimensional vectors.

**Vector Search** — Finding similar vectors using distance metrics (cosine, Euclidean).

## Z

**Zero-shot** — Model performing a task without any training examples for that task.
